Necromancer is a verification workbench for legacy COBOL migration.

- A compiled COBOL program is the oracle. A Python twin is tested against generated inputs.
- Every mismatch shows its input, both outputs, a field diff and the rule trace.
- Output is evidence over N cases. Never write "proven equivalent". Always show the denominator.
- All data is synthetic. The benefit rules are not any state's law.
- Humans approve each class of difference and the final candidate. Nothing is deployed automatically.
