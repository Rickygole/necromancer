# Design: workbench-ui

## Transport
FastAPI with server sent events for progress. One way streaming is enough.

## Panes
- The Crypt: source, record layout, claim picker.
- The Summoning Circle: run controls, verdict, counterexample cards, gates.
- The Resurrected Twin: twin source, trace comparison, recorded patch.

## Accessibility
Keyboard reachable, visible focus, reduced motion respected, status by icon and text.
