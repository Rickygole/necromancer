# Incidents caught by the harness and tests

Every entry below can be checked against `git log` and the files named. All commits carry the date 2026-11-12, so the order here follows commit order, not separate calendar days. No entry claims an AI tool found the problem. The catcher is named for each one.

- 2026-11-12: The first differential run of the blind twin against the compiled oracle failed with 5 mismatches in 45 cases. The harness shrank them to cx_0001 (class `base+net|t6.8`), cx_0002 (`net`) and cx_0003 (`net+offset`). The records are in `evidence/counterexamples/` and the run is `evidence/runs/run_20261113025841_1d9235/report.json`. Caught by the differential harness. Recorded in 0cdd90b, e37b15e, 0e651bb and 241fdab. The three classes were later given decisions in 102e7c6, 152c73c and 7924657 (dec_0001 to dec_0003).
- 2026-11-12: The twin store helper was called with widths that did not match the COBOL PIC clauses (9 digits for total wages where the field is 9(8)V99, 5 digits for fields declared 9(5)V99). Caught by the differential harness through the counterexamples above. Fixed in a4cabb6.
- 2026-11-12: Generated money fields reached 8 digits (99999999) for the 7 digit pension and severance fields, which produces records longer than 80 bytes. Caught by the record round trip property (P5 in `tests/test_properties.py`). Fixed in a991d74.
- 2026-11-12: The wage ceiling divided total wages by 52 before multiplying by 0.65, which differs from the COBOL expression `0.65 * WS-TOTAL / 52` on some inputs. It was not seen on the small corpus and showed up after batches were enlarged in 51bb89e. Caught by the differential harness. Fixed in 07635b9.
- 2026-11-12: The planned case count was estimated as batches times batch size before Hypothesis generated the batches, but generated batches vary in length, so the denominator shown did not equal the cases run. No failing test is recorded. Visible in the diff of 56faba3. Fixed in 56faba3 by generating the corpus first. The snapshot was re-recorded with exact counts in 97b4d56.
- 2026-11-12: Counterexamples found while a mutation was injected were saved as `cx_` files and could collide with real counterexample ids. No failing test is recorded. Fixed in 63093ba, which gives them the `mx_` prefix. The snapshot was re-recorded in af8b677.
- 2026-11-12: Two concurrent runs could both invoke the compiler on the same output binary. No failing run is recorded for this. Fixed in 758811f with a lock around the oracle build in `oracle/runner.py`.
- 2026-11-12: The console read `compiler` and `version` from the health response and used a fixed patch id, while the API returns `compiler_version`, `app_version` and ids of the form `fix-M4`. Caught by checking the console against the running app. Fixed in 890a18d.
